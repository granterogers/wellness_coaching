# Brand assets

| File | Use |
|---|---|
| `logo-ink.svg` | Full logo, ink (#15191A) for light backgrounds |
| `logo-light.svg` | Full logo, light (#E9E4DA) for dark backgrounds |
| `logo-currentcolor.svg` | Full logo that inherits the surrounding text colour (preferred in the site code) |
| `icon.svg` | Simplified mark (snake + orbit) for favicon and anything under ~64px; adapts to light/dark mode |
| `icon-180.png` | Apple touch icon |
| `logo-*-2048.png` | Transparent PNGs for social media, documents, WhatsApp |
| `logo-original.png` | Source file as supplied |

The SVGs were auto-traced from the original PNG. The full logo is detailed and should not be shown smaller than ~64px; use `icon.svg` below that. The icon is an interim design pending the human design review.
