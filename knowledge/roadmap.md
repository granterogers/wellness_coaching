# Roadmap

## Status (4 November 2026)

- Done: positioning, knowledge base, design research, master prompt, logo vectorised, UK operations plan (private repo)
- Next: homepage copy draft → three design prototypes → build in Claude Code → free preview link

## Steps

1. Draft homepage copy (Grant edits) → saved to `content/en/`
2. Three hero/homepage prototypes (field notebook / night practice / Mediterranean) using the real logo and copy → Grant picks one → saved to `design/`
3. Claude Code builds from `master-prompt.md`; publishes to GitHub Pages
4. Self-shoot easy photos; record voice clip
5. Feedback round: 5–10 testers via a short feedback form
6. Human design review (one hour with a working designer); include the logo
7. When satisfied: domain, email, booking, forms, payments, insurance (see private repo `strategy/operations-uk.md`)

## Logo — notes for refinement

- Strong concept: meditator inside an atom with kundalini snake = scientist turned practitioner
- Reads as male (bodybuilder physique, stern face) — at odds with a men-and-women audience
- Some AI-generation artefacts (hands, stray marks where orbits cross, uneven line weight)
- Options: redraw cleaner and more gender-neutral, or reduce to the orbit + snake mark (`assets/brand/icon.svg` is an interim version)
