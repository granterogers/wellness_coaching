# Copywriting brief

Copy is written and approved **before** any build. It lives in `content/en/` (Spanish in `content/es/`, translated after English is approved).

## Process
1. Draft homepage copy using `client-language.md` (real phrases from interviews), `offer.md` and `voice-and-messaging.md`.
2. Grant edits. Read aloud: if Grant wouldn't say it to a client across a table, rewrite it.
3. Mark the file `status: approved`. Only then does the build use it.
4. Spanish: translate, then native-speaker review, then `status: approved`.

## Rules
- Use the visitor's words, not wellness-industry words. Lift phrasing from `client-language.md` wherever possible.
- Specific beats general: "a five-minute routine you'll actually do on a Tuesday" beats "sustainable habits".
- Every practice gets a one-line reason ("Longer exhales shift you toward rest — that's why we start there.").
- Hedge honestly: "tends to", "research suggests". No guaranteed outcomes, no health claims.
- First person, short sentences, dry warmth. Name the trade-offs.
- Sexual wellbeing: only inside its pillar, plain and discreet; never in the hero, page titles or share images.
- No prices; investment is discussed on the call.
- Test each headline: could a competitor use it unchanged? If yes, rewrite.
- Where `voice-and-messaging.md` ("words that resonate") and `client-language.md` ("words they did not use") disagree, use the plain word in headlines, subheads and buttons; the technical term may appear once in body text, explained.
- Pillars: each needs a name, a one-line description, and one example practice with its one-line reason (the desktop index reveals these, requirement 5.4).

## Homepage sections to write
Hero (headline, subhead, 2 CTAs) · Recognition (problem, 3 observations) · Approach (3 principles) · Pillars (from `pillars-draft.md`) · Programme (4 phases) · About · Voice clip intro line + transcript · Proof (placeholders until real quotes) · FAQ (7–8) · Final CTA · Footer disclaimer line.
